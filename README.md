# Mini Bank

A simple Python banking system built as a practice project.

## Features

* Check balance
* Deposit money
* Withdraw money
* Input validation
* Prevents insufficient funds
* £10,000 deposit limit
* Exit option

## What I Practised

* `while` loops
* `if / elif / else`
* `try / except`
* User input
* Variables
* `float()` and `int()`
* Comparison operators
* Basic banking logic
* Formatting currency

## How to Run

Make sure Python is installed, then run:

```bash
python bank.py
```
